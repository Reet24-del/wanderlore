# Free Render demo

This deployment uses Render Free (512 MB), online Gemma through Google AI Studio's free tier, and ElevenLabs narration within the account's existing quota. It does not run Ollama or Kokoro on Render. The desktop installation still supports both local models.

No paid plan, disk, database, or automatic paid model fallback is configured. Render's free service sleeps after inactivity, and its filesystem is temporary. Export important walks before leaving; saved stories and audio can disappear on sleep, restart or redeploy. A private access code protects the demo's shared journal; it is not a public multi-user service.

Deploy `render.yaml` from the repository. Set `GOOGLE_API_KEY` and `ELEVENLABS_API_KEY` privately in Render. `WANDERLORE_PAIR_CODE` is generated by the blueprint; retrieve it from Render's environment settings to pair your phone. Never commit these values. Optional `SENTRY_DSN` enables scrubbed traces. Existing local databases, coordinates, credentials and recordings are excluded from the deployment.

Google receives story context, choices and nearby place names, but the generation adapter strips raw landmark coordinates and distances. Google free-tier prompts may be used to improve its products. GPS is processed by the Render server; ElevenLabs receives narration text. The site displays these disclosures. All services have quotas and require internet.

The public `/healthz` endpoint only reports liveness. Pair, generate a real chapter, play narration, and test GPS on a phone before claiming the deployment is verified. Model-key configuration alone is not a connection test.
